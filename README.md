# Portfolio (legacy)

An earlier single-page personal portfolio built with plain HTML, CSS and JavaScript. It uses an Apple-inspired visual system, a bento grid, animated hero copy and an experience timeline.

## Preview

Open `index.html` directly, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
